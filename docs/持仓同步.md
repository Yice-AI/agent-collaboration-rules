# 持仓同步

适用本规则的项目中，每当 Agent 确认新的持仓、成交、现金余额或资金转账状态，必须在本轮维护 `resources.holdings_sheet` 指向的既有私有表格，并在收尾前读回核验。只更新聊天、研究文档或近期记录不算完成。

这项保存不授权执行交易、转账、签名或认证，也不要求另建持仓系统、同名表格或后台任务。

## 数据职责与触发

表格保存已记录的持仓／现金快照及相关成交、转账状态。它不是实时行情或最终清算保证；推算和待核对标签须保留。

来源应为用户明确陈述已发生／当前成立的事实，或本轮实际读取且能定位账户与时间的截图、回单、授权账户连接。保留真实来源类型；助手旧回执、建议、目标配置、订单预览或日期到达不变成已确认业务。

| 新信息 | 必须维护的已确认部分 | 不能自动推出 |
|---|---|---|
| 持仓／成本快照 | 对应账户、标的、明确数量或成本、来源及截至时间 | 市值等于成本；旧快照可覆盖更新证据 |
| 成交／部分成交／更正 | 已成交部分、来源和状态；新持仓或成本有精确依据时再改相应字段 | 委托等于成交；未成交部分已成交；仅凭成交金额得出现金或总成本 |
| 现金余额 | 币种、明确余额口径与截至时间 | 购买力等于全部现金；可交易等于可提现；未知等于零 |
| 转出／在途／到账／失败／退回 | 对应资金动作的状态和来源；余额变化另有证据时才改现金 | 转出成功等于收款到账；失败等于退款；显示到账等于最终清算 |

只更新已确认部分，其余标待核对。币种列、计划内外口径和预留资金沿用原表定义；不同币种不能写进同一金额列或自行换算。结构无法表达时，保留私有证据和备注，明确待处理，不悄悄改列结构。

## 操作顺序

1. **读目标和旧值。** 从私有 manifest 定位同一 spreadsheet ID；读取当前元数据、所有者／共享权限、可见页签、相关表头、旧值、备注，按需读取公式、验证规则和单元格说明。页签和行号只是定位线索，不能据旧配置直接写。目标不符、权限扩大或必要范围读不全时暂停写入，不自行改共享权限。
2. **定位并排重。** 按账户、类型、标的、币种确定记录；按来源消息／截图／回单、业务时间及必要交易标识核对重复。已有相同事实且一致时读回确认，回执“已存在，无需重复”。部分成交按具体成交区分，更正保留旧来源和纠正说明。
3. **拟定最小改动。** 写清原值、确认的新值、来源日期、观察时间和记录时间。优先使用证据中的绝对快照，避免对已经包含某笔交易的余额再次加减。只有成交／转账事实、没有精确新余额或成本时，先写事实备注和待核对项，不能以信息不全为由完全漏记已确认状态。
4. **保留统计口径。** 账户间划转不创造新本金；计划内外、预留和在途金额不重复计入总数。归属未确认时不擅改统计列。确需新行时先排重，并沿用正确的格式、验证和公式；不整表重建。
5. **写前复核。** 再读拟改范围和去重依据。旧值变化、来源冲突或已知其他写入者正在修改时停止争用，先核对。只写相关单元格，保留无关数据、公式、格式与备注；相关字段尽量同批提交。
6. **读回验收。** 重新读取改动范围及必要关联行，核对值、状态、来源、日期、未改字段和统计口径，排除重复成交、重复本金和误清空。无法读回或结果不明时不称已同步；先读回排重，不生成新交易、不盲重试。
7. **独立保存关联记录。** 涉及确认链允许字段时按 [确认记录规范](确认记录规范.md) 保存；按 [近期记录规范](近期记录规范.md) 留进度和回执。数量、成本等不在确认链白名单的字段不得强塞进 HEAD，也不改固定基线。

目前这套 Sheets 流程不提供 Docs `requiredRevisionId` 式的条件提交保证。写前读取和同批更新不等于原子锁、跨表事务或完整并发安全；已知竞争下不能继续覆盖。任何新增条件写能力需另行核验后才能改变这一声明。

## 部分成功与失败

- **日志失败不能自动跳过表格。** 日志结构异常、容量不足或缺写入能力时，仍应完成独立满足授权、证据、权限、旧值及读回条件的表格维护，随后如实报告日志待保存。
- **确认链失败不能伪装成表格成功，反之亦然。** 不支持的字段不制造确认事件；需要进入确认链的字段也不能因表格成功而省略。失败处按自身规范处理，后续只补未完成部分。
- 表格响应不明时保留原来源和交易标识，先核对实际表格；不因超时就重复扣加或新建同名表。
- 缺工具、权限、足够证据或发生冲突时，主动提供 [待保存摘要](../templates/待保存摘要.md)：已确认事实、来源／日期、旧值是否已读、目标页签／范围、具体阻塞及下一步。不得编造旧值或用历史基线代存。
- 表格、确认链和日志各自已核验的结果不因其他一处失败而自动回滚。未读回的部分不说已跨端保存。

## 收尾回执

涉及上述事实时给出私有表格链接、页签／范围、事实截至时间与来源、更新内容和读回状态。没有数字变化也说明是重复事实、仅状态变化还是证据不足。

`持仓表：已同步／已存在无需重复／待同步／写入结果待核验；链接；范围；来源及截至时间；读回结果。确认链：已保存／无需变更／待保存／结果待核验。近期记录：版本和记录 ID／待保存原因。`

规则发布、读取表格、编辑说明、真实业务更新、自然聊天触发、无人值守、并发和下游空间刷新是独立验收项。没有对应实测时不能称所有 Agent 已生效或后台同步已建立。
